## Descrição do Projeto

Este é um projeto desenvolvido como parte de um exercício prático, que consiste na criação de um backend para uma farmácia utilizando Spring Boot. O sistema permite o gerenciamento de produtos e categorias, garantindo a organização e manipulação dos dados de maneira eficiente.

## Funcionalidades

✅ CRUD completo para Categorias (6 métodos)

✅ CRUD completo para Produtos (6 métodos) com relacionamento com Categoria

✅ Configuração do banco de dados no application.properties

✅ Validação do pom.xml e do application.properties

## Tecnologias Utilizadas

☕ Java

🌱 Spring Boot

📦 Spring Data JPA

🗄️ MySQL

🔨 Maven

🏗️ Hibernate
